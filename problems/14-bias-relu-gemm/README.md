# 14 · 带列偏置和 ReLU 的分块矩阵乘法

一个线性层要计算 `Y[i,j] = max(0, sum_t A[i,t] * B[t,j] + bias[j])`。用一次内核启动完成，直接写回激活结果。每个块负责输出的一块矩形。

## 输入与输出

`solve(a, b, bias, out, m, n, k)`。四个缓冲区均为连续的 float32，形状依次为 `(m,k)`、`(k,n)`、`(n,)` 和 `(m,n)`。标量为 int32。用例中的输入是 −2 到 2 之间 0.25 的整数倍，最大内积长度为 257，判题逐元素精确比较。任一维度均可为零。若仅 k 为零，每一行仍须写入截断后的偏置。

例如 `A=[[1,-2]]`，`B=[[2,1,0],[1,-1,2]]`，`bias=[-1,-2,3]`。内积得到 `[0,3,-4]`，加偏置并截断得到 `[[0,1,0]]`。

## 从内积到分块

1. 令每块负责 16×16 个输出。沿 k 方向每次取 A 的 16×16 子块和 B 的 16×16 子块。越界的乘数补零。
2. CUDA 使用 `(16,16,1)` 个线程。装填共享内存后同步，更新累加器后再同步一次，否则下一轮写入可能覆盖同块线程仍在读取的数据。边缘线程也参与两次同步。
3. Triton 使用 `TILE=16`，横向程序编号对应输出列块。参考解利用本题输入能以 FP16 精确表示的性质，用 `tl.dot` 做块乘并保留 FP32 累加器。遍历完所有 k 块才加一次偏置。

先把 k 设为 0，再试 `m=17, n=31, k=33`，分别检查偏置广播和三个方向的尾块。
