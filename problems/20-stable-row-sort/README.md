# 20 · 有符号键的稳定行排序

给每行事件按优先级升序排列，返回事件原来的列号。优先级相等时，较早出现的事件排在前面。例如一行键为 `[3,-2,3,-2]`，输出应为 `[1,3,0,2]`。

`solve(keys, order, rows, width)`。缓冲区和标量都是 int32，两张矩阵都按行连续。行宽为 0 到 1024，输入可包含 int32 两端的极值。每个输出行都必须是该行所有列号的一个排列。

**思路**　先把有符号键的符号位翻转，再将其拼进无符号 64 位数的高半部，低半部保存原始列号。按这个复合键排序即可保留相同优先级的先后。非二次幂宽度用全 1 的复合键补齐。即使真实键等于 INT_MAX，其低半部依然小于这个填充值。

CUDA 用一个 128 线程块处理一行，在共享内存中运行双调排序网络。每次比较交换由一条线程负责两个位置，每层结束时整个块同步。Triton 每个程序处理一行，用 BLOCK 表示补齐后的长度，排序后写回低 32 位。可以用第 6 例检验 513 个真元素与 511 个补位共存的情况。
